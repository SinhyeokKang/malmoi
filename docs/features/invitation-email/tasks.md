## T3. UI

- [ ] **T3.1** 모달을 행별 이메일·역할·추가/삭제·붙여 넣기 폼으로 바꾼다. 성공은 닫기+토스트, 오류는 입력 유지+행 오류/폼 Alert. 기존 링크 화면과 복사 로직을 제거한다.
  - 검증: DOM에서 역할 보존·중복·붙여 넣기·Enter/IME·pending 잠금·통신 오류 해제·성공 닫기·오류 입력 보존·행 삭제 후 포커스/가짜 성공 없음. 기존 `installFocusFixup`을 유지하고 pending 해제 뒤 첫 오류 행으로 복귀함을 단언한다. 복귀 호출 제거 시 red와 실제 브라우저 착지점도 확인한다. 단순화와 무관한 기존 코드는 고치지 않는다.
- [ ] **T3.2** Pending에 Resend를 붙인다. 처리 중 해당 행 Resend/Revoke 잠금, 결과는 목록 재검증 후에도 살아 있는 부모 피드백으로 전달한다.
  - 검증: 성공/거부/unknown, 교체된 행 id에서도 메시지 미소실, 마스킹 라벨, 새 모달·링크·배지 없음. 사전 거부로 행이 남으면 잠금 해제 뒤 Resend 버튼, 성공 또는 발급 후 메일 실패로 행이 교체되면 Pending 카드 제목에 포커스가 닿는다. DOM은 focus-fixup 보정과 복귀 호출 제거 시 red를 확인한다. 실제 브라우저에서도 각 착지점·긴 목록·1280×720·키보드·Resend/Revoke 높이36을 확인한다.
- [ ] **T3.3** 기존 로그인·초대 수락 회귀 및 전체 게이트를 실행한다.

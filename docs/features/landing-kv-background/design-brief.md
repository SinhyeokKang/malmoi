# landing-kv-background — Claude Design 브리프 (`lg` 미만)

> **이 시안은 이 기능의 첫 구현 동안만 SoT다.** 구현이 dev에 들어간 뒤로는 코드 + DESIGN §6.615가 정본이고, 새 시안은 변경 요청이다.
> 기능 정의는 `spec.md`, 구조·판정은 `design.md`가 정본이다. 1280 이상은 이미 `Landing KV Background.dc.html`(3a–3h · 2a–2c)과 `Landing KV Background Guide.dc.html`이 정했다 — **이 브리프는 그 시안에 없는 `lg`(1024) 미만만 그린다.**

## 한 줄

`/` 랜딩의 스크롤 콘텐츠 전체에 깔리는 KV 배경(세로 그라디언트 + 커서 추종 점 격자)을 **태블릿·모바일 폭**에서 그린다. 사용자 결정(2026-10-18): `lg` 미만에도 적용하고 숨기지 않는다. CTA 아래 끝은 1280 시안과 같다(CTA 아랫변 = 패널 바닥에서 끝).

## 프리미티브 · 값

새 프리미티브·새 색 없음. 그라디언트 `--auth-hero-from` → `--auth-hero-to`, 점 `--signin-dot`(Light `#2563eb` · Dark `blue-400`), `DotField` 상수(간격 16 · 반지름 2→3.5 · 알파 0.08→0.3 · 커서 반경 180)는 1280 시안과 **같다** — 좁은 폭용으로 조정하지 않는다(design §1). 격자 16은 폭과 무관하게 고정이다.

문구 변경 없음. 상태는 스크롤 위치와 테마뿐이다.

| 상태 | 무엇이 보이나 |
|---|---|

## 동작 주석

- 스크롤하면 점 격자는 콘텐츠에 붙어 올라가고(16px마다 한 칸), 그라디언트는 콘텐츠와 함께 움직인다. 캔버스 자체는 화면에 고정(sticky)이다.
- 점은 내용 아래에 그려진다 — 버튼·문구 위로 오지 않는다. 탭·포커스·키보드 스크롤은 지금과 같다(캔버스는 포인터를 받지 않는다).
- `prefers-reduced-motion`이면 점은 정적이고 스크롤할 때만 다시 그려진다.

## 그리지 않는 것

- `/signin`의 좁은 폭 KV — 로그인은 지금처럼 `lg` 미만에서 장식을 숨긴다.
- `/docs`·`/privacy`·`/changelog`의 배경.
- 목업 프레임·베젤·캡션 줄의 투명도·블러.
- 새 색·점 크기·간격 조정 — 1280 시안과 같은 값이다.
- CTA 아래 끝의 다른 처리(페이드·푸터까지 연장) — 사용자가 1280 시안대로로 정했다.

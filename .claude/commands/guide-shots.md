`public/guide/*.webp`(가이드 본문이 `/guide/<name>.webp`로 참조하는 스크린샷)를 **실제 앱을 조작해 다시 찍는** 전용 스킬. 본문은 건드리지 않는다 — 본문은 `/guide`, 이미지는 여기.

규격·환경·마스킹 표·에셋 매핑 표·알려진 벽·진행 상태는 전부 **`guide/SHOOTING.md`가 단일 출처**다. 이 스킬은 그 문서를 로드해 실행하는 손이고, 여기에는 **런타임 분기와 기록 계약**만 둔다. **stale 판정은 여기 없다** — `pnpm guide:check`가 정본이다.

## 런타임 능력 판정 (가장 먼저)

**제품 이름이 아니라 능력으로 판정한다.**

| # | 필요 능력 | 왜 대체 불가인가 |
|---|---|---|
| 1 | **ego-browser** 스킬(로그인 세션을 쓰는 실 브라우저) | 찍을 대상이 로그인 뒤의 편집 UI다 |
| 2 | 로컬 `pnpm dev` + dev DB 접속(`.env.local`) | preview는 SSO 뒤이고, 촬영 데이터는 dev DB의 상주 QA 프로젝트다 |

하나라도 없으면 **`check`까지만** 수행하고 촬영 없이 종료한다. `check`는 `pnpm guide:check`(작업 트리의 `git hash-object`만 본다)라 **어느 런타임에서든 돈다** — Codex에서도 "지금 몇 컷이 낡았나"를 싸게 물을 수 있다. ⚠️ **이 스킬은 Codex 미러에서 제외돼 있다**(`scripts/sync-agents.mjs`의 `EXCLUDE`) — Codex에는 1이 없다.

## 사용

- `/guide-shots` — stale 목록을 받아 낡은 컷만 재촬영.
- `/guide-shots check` — **목록만** 내고 촬영 안 함. 어느 런타임에서든.
- `/guide-shots <에셋…>` — 지정 컷만. 예: `/guide-shots /guide/invite.webp`.
- `/guide-shots all` — 매핑 표 전량 재촬영.

## 절차

### 1. 전제 확인

- `guide/SHOOTING.md`를 **먼저 전문으로 읽는다**(상수·환경·마스킹·매핑·벽·진행 상태).
- **진행 상태** 절에 이전 세션이 남긴 재개 지점이 있으면 거기서 이어간다.

### 2. stale 목록

**`pnpm guide:check`를 돌려 출력을 그대로 인용한다.** ⚠️ **판정을 여기서 다시 짜지 않는다**(git 시각 비교·소스 추측 금지 — dev→main squash와 `/sync` hard reset이 시각 신호를 지운다).

| reason | 뜻 | 할 일 |
|---|---|---|
| `changed` | 매핑 소스의 현재 SHA가 기록과 다르다 | 재촬영 |
| `deleted` | 매핑 소스가 작업 트리에 없다(삭제·이동) | 새 소스로 매핑을 고치고 재촬영 |
| `invalid` | 매핑 소스가 리포 밖·비정규 경로(절대경로·`..`·백슬래시)다 — 해시하지 않는다 | 리포 루트 기준 상대 경로로 표를 고친다 |
| `unrecorded` | blob이 비었다(아직 안 찍었거나 기록 누락) | 촬영 후 기록 |
| `count-mismatch` | 소스 수 ≠ blob 수 | 표를 고친다(순서로 짝짓는 계약이다) |

**`check`는 여기까지** — 목록 + 알려진 벽에 걸린 컷을 따로 표시해 보고하고 종료한다.

`changed`가 떴다고 화면이 실제로 바뀐 것은 아니다(주석 한 줄도 SHA를 바꾼다). 재촬영 전에 매핑 소스의 diff를 보고 **화면이 그대로면 다시 찍지 않고 SHA만 갱신**한다 — 그 판단을 리포트에 남긴다.

### 3. 촬영 환경

- **`pnpm dev`를 다시 띄운다** — dev 서버가 도는 중에 `pnpm build`를 돌리면 서버 컴포넌트가 낡은 채로 남는다.
- SHOOTING 환경 절 그대로: dev DB 상주 QA 프로젝트 + OWNER/EDITOR 계정. **편집자 장의 컷은 EDITOR 계정으로 찍는다** — EDITOR에게 안 보이는 버튼이 편집자 가이드 이미지에 있으면 거짓이다.
- viewport·DPR은 SHOOTING 상수대로. 촬영 직전에 실제 `innerWidth`·`devicePixelRatio`를 확인한다.

### 4. 마스킹 (공개 문서 전제)

`/docs`는 공개 라우트다. SHOOTING **마스킹 표**(`원본` → `치환`)를 **촬영 직전 DOM 텍스트 노드에** 적용한다. 새 화면에서 개인·회사 식별 문자열(계정명·리포명·이메일)이 보이면 표에 먼저 추가한다. `pnpm test`가 마스킹 원본 문자열이 md에 0임을 본다 — **픽셀 안의 문자열은 못 본다**, 컷마다 눈으로 확인한다.

### 5. 촬영 · 확인

- SHOOTING 규격대로 부분 크롭. **액자·배경을 파일에 굽지 않는다**(CSS가 그린다).
- **결과를 바로 리포에 쓰지 않는다.** 스크래치패드에 모아 WebP로 변환하고(`sharp` — 일회성 스크립트는 `.scratch/`), 컷마다 눈으로 확인한 뒤(마스킹·잘림·표시 기준 최소 글자 크기) `public/guide/`에 반영한다.

### 6. 기록 (계약 — `pnpm guide:check`·이미지 게이트가 읽는다)

SHOOTING **에셋 매핑 표**(`## 에셋 매핑 {#shots}`)의 해당 행을 갱신한다:

| 열 | 값 |
|---|---|
| `에셋` | `/guide/<name>.webp` |
| `소스` | 그 화면을 그리는 리포 경로 — **쉼표로 가른다** |
| `blob` | 소스마다 `git hash-object <경로>` — **`소스`와 같은 순서, 같은 개수** |
| `치수` | 파일의 실제 픽셀 `WxH`(`sharp` 메타데이터). `pnpm test`가 파일과 대조하고 렌더러가 `width`·`height`로 쓴다 |

- ⚠️ **blob은 촬영한 그 작업 트리에서 잰다** — 소스를 고친 뒤 찍었으면 고친 뒤의 SHA다. 기록 뒤 `pnpm guide:check`가 그 컷을 더 이상 내지 않아야 한다.
- 새 에셋이면 본문 참조가 필요하다 — 이 스킬은 본문을 안 고치므로 리포트에 적고 `/guide`로 넘긴다(본문 참조 없는 파일은 이미지 게이트가 고아로 red를 낸다 — 같은 커밋에 들어가야 한다).
- **진행 상태** 절을 갱신한다: 찍은 컷 · 남은 컷 · 새로 밟은 함정. **기록하지 않으면 다음 세션이 같은 벽에서 다시 막힌다.**

### 7. 검증 + 보고

`pnpm test`(이미지 게이트 — 참조 해소·고아 0·alt·치수·매핑 전수·마스킹 원본 0) + `pnpm guide:check`(방금 찍은 컷이 목록에서 빠졌는가).

```
런타임: 촬영 가능 / check 전용(<없는 능력>)
guide:check (전): <출력 인용>
재촬영: <에셋 목록> / SHA만 갱신: <에셋 — 화면 불변 근거>
벽: <촬영 불가 컷 — SHOOTING 벽 절>
마스킹: <표 추가 항목 또는 없음>
guide:check (후): <출력 인용>
검증: pnpm test <n> passed
본문 후속: 없음 / /guide 필요(<새 에셋 참조>)
```

- 보고 후 **종료**. 빌드·커밋·푸시 안 함(커밋은 `/ship`·사용자가 `docs(guide): …`로).

## 알려진 벽

SHOOTING 벽 절이 단일 출처. 요약: **GitHub App 설치 왕복**(①의 1클릭 설치·요청 복귀·승인 복귀)은 로컬에서 못 밟는다 — 설치 URL이 `redirect_uri`를 안 받아 프로덕션 callback으로 간다. stale로 잡혀도 자동 촬영을 시도하지 말고 리포트에만 남긴다. GitHub 쪽 화면은 github.com에서 찍는다.

## 금지 사항

- **SHOOTING.md 안 읽고 시작 금지.**
- **stale 판정 복제 금지** — `pnpm guide:check`를 인용한다.
- **능력 없는 런타임에서 촬영 시도 금지** — `check`만.
- **본문(`guide/**.md` 페이지) 수정 금지** — `/guide` 몫. 이 스킬이 고치는 `guide/` 파일은 `SHOOTING.md` 하나다.
- **코드 수정·`pnpm build`·커밋·푸시 금지.**
- **마스킹 미적용 컷 반영 금지** — 공개 라우트다.

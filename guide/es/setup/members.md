# Invita a traductores

Invita a tus compañeros por correo electrónico y elige el rol que necesita cada persona.

Los propietarios del proyecto gestionan las invitaciones y los miembros. La persona invitada acepta el enlace del correo, inicia sesión con la dirección invitada y aparece en el proyecto con el rol que eligió el propietario.

## Elige un rol {#roles}

Elige **Propietario** solo para quien deba gestionar la conexión con el repositorio, **Fuentes**, los miembros, el estado de archivado, **Sincronizar** o **Revertir a lo último enviado**. Elige **Editor** para los traductores que necesitan editar traducciones y **Publicar**. No se puede quitar ni degradar al último Propietario.

## Envía invitaciones {#invite}

1. Abre **Miembros**.
2. Elige **Invitar miembro**.
3. Introduce las direcciones y elige un rol para cada fila.
4. Envía las invitaciones.

![El diálogo Invitar miembros con dos direcciones de correo, el rol Editor elegido para ambas y un botón para enviar las dos invitaciones](/guide/invite-members.webp "Introduce cada dirección, elige un rol y envía las invitaciones.")

Si alguna dirección superara un límite, no se envía ninguna invitación. Un correo fallido cuenta igualmente para el límite por hora.

Cada dirección aparece en **Invitaciones pendientes** cuando se crea la invitación. Comprueba el resultado del envío antes de cerrar el cuadro de diálogo de invitación; que una invitación aparezca en la lista no significa por sí solo que el correo haya llegado.

## Gestiona los miembros {#members}

Los propietarios del proyecto pueden cambiar el rol de un miembro, elegir **Quitar** para un miembro o gestionar las **Invitaciones pendientes** con **Revocar** y **Reenviar**. El rol de una invitación pendiente no se puede cambiar; revócala e invita de nuevo a la dirección. Consulta [Únete a un proyecto](../translate/join.md) para ver los pasos de quien recibe la invitación.

![La lista de Miembros con un Propietario y un Editor, cada uno con un menú de rol y un botón Quitar, encima de una lista vacía de invitaciones pendientes](/guide/members.webp "Cambia un rol o quita a un miembro de la lista.")

## Qué pasa después {#next}

La persona destinataria sigue el enlace de la invitación e inicia sesión con la dirección invitada.

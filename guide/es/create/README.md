# Crea un proyecto

Conecta un repositorio de GitHub o GitLab.com y elige los archivos de traducción que Malmoi debe gestionar. Para crear un proyecto necesitas acceso de escritura al repositorio.

Los pasos dependen de dónde está tu repositorio. Sigue la página de tu servicio de repositorios desde el primer paso hasta el final; las páginas que vienen después configuran las actualizaciones automáticas para ese servicio.

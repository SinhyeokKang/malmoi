# Crea un proyecto

Conecta un repositorio de GitHub o GitLab.com y elige los archivos de traducción que Malmoi debe gestionar. Para crear un proyecto necesitas acceso de escritura al repositorio.

Elige [GitHub](../github/README.md) o [GitLab](../gitlab/README.md) para seguir los pasos de configuración de tu repositorio. La guía de cada servicio también cubre CI, la fusión de traducciones, la gestión de conexiones y la solución de problemas.

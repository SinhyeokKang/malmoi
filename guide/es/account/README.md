# Cuenta y preferencias

Gestiona cómo inicias sesión en Malmoi y cómo ves sus pantallas.

Cuenta reúne tu perfil, tus métodos de inicio de sesión, la conexión con GitHub y tus sesiones. Preferencias define el idioma de la interfaz, la zona horaria y el tema. Ambas están en el menú de tu avatar, arriba a la derecha, y ninguna cambia tus proyectos.

# Limits

Check the fixed limits for projects, members, invitations, and translation files.

## Project and member limits {#limits}

You can own up to `3` projects. A project can have up to `10` members. A project address can be up to `40` characters. Archiving a project frees a project slot; pending invitations do not count until they are accepted.

## Invitation limits {#invitations}

A project can send up to `20` invitations in one hour. The address cooldown and the project hourly window apply to both the initial invitation and Resend.

## File and translation limits {#files}

Initial setup accepts up to `200` files, `2MB` per file, and `10MB` total. A repository request accepts up to `20,000` keys, `200` languages, `10,000` characters per value, and `200,000` rows.

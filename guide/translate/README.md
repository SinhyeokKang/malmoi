# Translate

Join your team, save translations, and publish saved changes for review in GitHub.

Editors use this chapter to accept an invitation, work in the translation screen, and send saved changes for review. Project owners remain responsible for repository settings and membership.

## Start translating {#start-translating}

Begin with [Join a project](join.md), then [Edit translations](edit.md). When the saved values are ready, open [Publish](publish.md).

# Malmoi

Malmoi는 GitHub 리포지토리의 번역 파일을 찾아 팀원이 Git 없이 브라우저에서 편집하게 하고, 저장한 변경 사항을 PR 하나로 보냅니다.

Malmoi라는 이름은 흩어진 말을 함께 모아 하나로 만들었던 1910년대 조선어사전 편찬 사업 ‘말모이’에서 왔습니다.

프로젝트를 설정해 리포지토리를 연결하거나, 팀에 참여해 번역을 편집하고 게시하세요.

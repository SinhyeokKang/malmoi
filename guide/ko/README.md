# Malmoi

Malmoi는 GitHub 저장소를 위한 로컬라이제이션 도구입니다. 저장소에 이미 있는 번역 파일을 찾아내고, 팀원이 Git 없이 브라우저에서 번역을 편집하게 하며, 저장된 변경 사항을 개발팀이 검토할 풀 리퀘스트 하나로 돌려보냅니다.

프로젝트를 설정해 저장소를 연결하거나, 팀에 참여해 번역을 편집하고 게시하세요.

# Malmoi

Malmoi는 GitHub 리포지토리의 번역을 관리하는 도구입니다. 리포지토리에 이미 있는 번역 파일을 찾아 팀원이 Git 없이 브라우저에서 편집할 수 있게 하고, 저장된 변경 사항을 개발팀이 검토할 PR(pull request) 하나로 보냅니다.

프로젝트를 설정해 리포지토리를 연결하거나, 팀에 참여해 번역을 편집하고 게시하세요.

# 워크플로 추가

생성된 GitHub Actions 워크플로를, GitLab 프로젝트라면 생성된 CI 작업을 추가해 리포지토리의 변경 사항을 Malmoi에 반영합니다.

시작하기 전에: **Malmoi 준비 완료** 페이지의 푸시 토큰을 준비합니다. 워크플로 파일을 커밋하기 전에 시크릿부터 저장하세요.

## 시크릿 저장 {#push-token}

1. GitHub에서 리포지토리의 **Settings**를 열고 **Secrets and variables**, 이어서 **Actions**를 선택합니다.
2. **New repository secret**을 선택하고 `PUSH_TOKEN`을 입력한 뒤 푸시 토큰을 붙여 넣고 저장합니다.

![이름에 PUSH_TOKEN을 입력하고 값 칸은 비어 있는 GitHub 새 시크릿 양식](/guide/push-token-secret.webp "이름에 PUSH_TOKEN을 입력하고 푸시 토큰을 붙여 넣은 뒤 시크릿을 추가합니다.")

## 워크플로 추가하기 {#workflow}

1. **Malmoi 준비 완료** 페이지에서, 또는 나중에 **설정**에서 워크플로를 복사해 리포지토리에 `.github/workflows/malmoi-i18n.yml`로 저장합니다.
2. 조직이 action을 제한한다면 [action 허용](allowed-actions.md)을 따릅니다.
3. 설정할 때 고른 기준 브랜치에 파일을 커밋합니다. 생성된 워크플로에는 소스마다 단계가 하나씩 있습니다.

![생성된 YAML과 복사 버튼이 보이는 Malmoi 설정의 워크플로 파일 대화상자](/guide/workflow-file.webp "YAML을 복사해 .github/workflows/malmoi-i18n.yml로 저장합니다.")

코드가 기본값 `@/i18n#t`가 아닌 래퍼 함수로 번역을 읽는다면, 그 단계의 `with:` 아래에 `wrapper` 입력을 추가합니다. 일반 함수는 `module#export`로, 훅은 `next-intl#useTranslations()`처럼 끝에 `()`를 붙여 씁니다. 래퍼가 여러 개면 YAML `|` 블록에 한 줄에 하나씩 씁니다. 설정 과정에서는 이 입력을 묻지 않습니다. 이 입력은 Malmoi가 코드 사용처를 찾는 데 도움을 줄 뿐, 어떤 번역 키가 있는지를 정하지는 않습니다.

`github-token` 입력은 읽기 전용이며 열린 PR을 알리는 데만 쓰입니다.

### 예전 워크플로 업데이트 {#update-workflow}

`malmoi-i18n-push-v1`이나 `malmoi-i18n-push-v2`를 쓰는 워크플로는 그대로 계속 동작합니다. `malmoi-i18n-push-v3`로 옮기려면 Malmoi에서 **설정**을 열고 **워크플로 파일**을 선택해 파일 전체를 복사한 뒤 `.github/workflows/malmoi-i18n.yml`을 그것으로 교체합니다. 그다음 `wrapper` 입력, 직접 지정한 `api-url`, 수정한 트리거처럼 손으로 바꿨던 부분을 다시 넣습니다. 생성된 파일에는 이것들이 없으며, `wrapper`가 빠지면 실행은 성공으로 끝나지만 코드 사용처가 더 이상 나타나지 않습니다. 버전 3은 Malmoi PR이 열려 있거나 확인하지 못해 업데이트가 보류되면 실행 로그에 경고를 남기고, YAML 파일의 숫자처럼 Malmoi가 관리하지 않는 값이 있어도 실행을 실패로 처리하지 않습니다 — 그 키만 경고와 함께 건너뜁니다. 버전 1에서 옮긴다면 버전 2의 변경도 함께 적용됩니다. Node 24에서 실행되므로 실행 로그에서 Node 20 지원 중단 경고가 사라지고, 버전 1이 통과시키던 일부 실행을 실패로 처리합니다. JSON이나 YAML 파일에 같은 키가 두 번 정의된 경우, `api-url`이 HTTPS가 아닌 경우, 언어 파일을 읽을 수 없는 경우가 그렇습니다. 셀프 호스팅한 Malmoi가 생성한 워크플로에는 그 사이트 주소를 가리키는 `api-url` 줄이 항상 들어 있으므로, 복사한 파일에 이미 있습니다. 그대로 둡니다.

## GitLab CI 작업 추가 {#gitlab-ci}

GitLab 프로젝트는 GitHub Actions 워크플로 대신 `.gitlab-ci.yml`의 CI 작업을 씁니다. [action 허용](allowed-actions.md)은 해당하지 않습니다.

1. GitLab에서 프로젝트 설정의 CI/CD, 이어서 Variables로 가서 이름이 `PUSH_TOKEN`이고 값이 푸시 토큰인 변수를 추가합니다. Protect variable과 Mask variable을 켭니다.
2. 고른 기준 브랜치가 GitLab에서 보호 브랜치인지 확인합니다. 따로 바꾸지 않았다면 GitLab은 기본 브랜치를 보호합니다. 보호 변수는 보호 브랜치에만 전달되므로, 보호되지 않은 브랜치에서는 `PUSH_TOKEN`이 없어 작업이 실패합니다.
3. **Malmoi 준비 완료** 페이지에서, 또는 나중에 **설정**의 **CI 파일**에서 작업을 복사해 리포지토리 루트의 `.gitlab-ci.yml`에 추가합니다. 파일이 이미 있으면 그 안에 덧붙입니다.
4. 기준 브랜치에 파일을 커밋합니다.

소스마다 작업이 하나씩 있고, 작업 이름에 프로젝트 주소가 들어가므로 한 리포지토리의 두 프로젝트가 서로의 작업을 덮어쓰지 않습니다. 작업은 기준 브랜치에 새 커밋이 들어올 때만 실행되며, `[skip-malmoi-i18n]`이 든 커밋은 건너뜁니다. 작업은 `test` 단계(stage)를 씁니다. 파일에 `stages:`를 직접 정의했다면 그 목록에 `test`를 남겨 두세요. 러너는 github.com(작업마다 고정된 버전의 Malmoi 스크립트를 받아 옵니다), registry.npmjs.org, Malmoi에 접속할 수 있어야 합니다.

코드가 래퍼 함수로 번역을 읽는다면 그 소스 작업의 `variables:` 아래에 `MALMOI_I18N_WRAPPER`를 추가하고, 위 `wrapper` 입력과 같은 형식으로 한 줄에 하나씩 씁니다. 나중에 기준 브랜치를 바꾸려면 **설정**에서 **기준 브랜치**를 바꾸고 `MALMOI_I18N_BASE_BRANCH` 값을 고칩니다. 소스를 추가하면 **설정**에서 파일 전체를 다시 복사해 Malmoi 작업을 그것으로 교체합니다.

Malmoi에 이 버전의 Malmoi에서는 아직 GitLab CI 파일을 쓸 수 없다고 표시되면 복사할 작업이 없습니다. 푸시 토큰은 보관해 두세요. CI 파일을 쓸 수 있게 될 때까지는 [야간 실행](../sync/nightly.md#repository-changes)과 **동기화**가 리포지토리 변경 사항을 가져옵니다.

## 실행하고 확인하기 {#first-run}

기준 브랜치에 워크플로를 커밋하면 실행이 시작됩니다. 다시 실행하려면 GitHub **Actions**를 열고 워크플로를 고른 뒤 **Run workflow**를 선택합니다. 실행 로그를 확인하세요. `applied`는 파일을 반영해 Malmoi의 **소스**를 업데이트했다는 뜻입니다. 미전송 변경 사항이 있으면 성공한 실행도 `deferred`를 보고할 수 있습니다. 이때 리포지토리 업데이트는 보류되며 로그에는 **보류**로 표시됩니다. [코드가 바뀌면](../sync/push.md#deferred)을 참고하세요. 실패한 실행은 로그에 이유를 보여 줍니다. GitLab에서는 기준 브랜치에 커밋하면 작업이 시작되고, 다시 실행하려면 파이프라인에서 그 작업을 다시 실행합니다. 결과는 작업 로그에서 같은 방식으로 읽습니다. Malmoi에서는 홈의 **동기화** 탭이 최근 동기화를 보여 줍니다. **마지막 동기화**에 **CI 동기화**가, **결과**에 그 결과가, **변경**에 바뀐 번역 수가 표시됩니다. **동기화 로그**에는 모든 동기화가 나열됩니다.

나중에 기준 브랜치를 바꾸려면 **설정**에서 **기준 브랜치**를 바꾸고 **저장**을 선택한 뒤 워크플로의 `branches:` 값을 고칩니다. 소스의 기준 언어를 바꿨다면 [소스 추가](sources.md#base-language)를 따라 워크플로 항목을 고칩니다.

## 다음 단계 {#next}

첫 실행이 성공하면 Malmoi가 키의 코드 사용처를 보여 줄 수 있습니다. 이후 실행이 실패해도 프로젝트는 준비된 상태로 남습니다.

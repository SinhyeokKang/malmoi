# GitHub 연결

GitHub 계정과 리포지토리를 연결하면 Malmoi가 번역 파일을 읽고 번역 PR을 보낼 수 있습니다.

시작하기 전에: 인증된 이메일로 로그인하고 **프로젝트**로 가서 **새 프로젝트**를 선택합니다. 활성 프로젝트는 세 개까지 소유할 수 있습니다. 연결은 새 프로젝트의 첫 단계입니다.

## GitHub 리포지토리 고르기 {#connect-github}

1. GitHub가 연결되어 있지 않다면 **GitHub App 설치**를 선택합니다. 조직에 이미 설치되어 있다면 **계정 연결**을 선택합니다. 설치 버튼을 쓸 수 없으면 **GitHub App 승인**을 선택하고, 관리자에게 설치 권한을 요청하라는 안내가 나오면 따릅니다. 리포지토리가 이미 목록에 있다면 아래로 넘어갑니다.
2. 리포지토리가 목록에 없으면 **리포지토리 추가**을 선택해 GitHub에서 앱 설치 화면을 엽니다. **Repository access**에서 **Only select repositories**를 고르고 리포지토리를 추가한 뒤 저장합니다.
3. Malmoi에 **승인 대기 중**이 표시되면 조직 소유자에게 승인을 요청한 뒤 **다시 시도**를 선택합니다.
4. 리포지토리를 고르고 번역 파일이 있는 **브랜치**를 고른 뒤 **다음**을 선택합니다. 이 브랜치가 Malmoi가 읽고 번역 PR을 보내는 기준 브랜치입니다.

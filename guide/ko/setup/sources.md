# 소스 추가

나중에 번역 파일을 더 추가하거나 소스의 기준 언어를 바꿉니다.

소스 하나는 리포지토리에 있는 번역 파일 묶음 하나입니다. 프로젝트 소유자는 소스를 추가하고 기준 언어를 선언할 수 있고, 번역자(편집자 역할)는 소스 상태를 볼 수 있지만 프로젝트 설정은 바꿀 수 없습니다.

## 소스 열기 {#sources}

프로젝트 내비게이션에서 **소스**를 엽니다. 행마다 소스의 상태(**아직 동기화 안 됨**, **동기화 중…**, **동기화됨**, **일부 동기화됨**, **동기화 실패**)와 키·언어 수가 표시됩니다.

![파일 경로, 키 수, 언어가 표시된 동기화된 소스 두 개가 있는 소스 페이지](/guide/sources.webp "소스 하나는 번역 파일 묶음 하나입니다.")

## 소스 추가하기 {#add-sources}

1. **소스 추가**를 선택하고, 감지된 파일을 고르거나 지원하는 경로를 입력합니다.
2. 고른 묶음마다 **기준 언어**를 고르고 **선택한 소스 추가**를 선택합니다. 다른 파일은 추가되는데 한 파일만 실패할 수 있으니 결과를 하나씩 확인합니다.
3. 결과의 **설정** 링크를 따라가 생성된 워크플로에서 새 소스 단계를 복사해 리포지토리의 워크플로 파일에 넣습니다. 소스를 추가해도 그 파일은 자동으로 수정되지 않습니다.

![왼쪽에 감지된 번역 파일, 키와 값 미리보기, 기준 언어 메뉴가 있는 소스 추가 대화상자](/guide/add-sources.webp "파일을 고르고 미리보기를 확인한 뒤 기준 언어를 고릅니다.")

## 기준 언어 바꾸기 {#base-language}

1. **소스**에서 소스의 상세를 엽니다. **기준 언어**에서 원문을 작성한 언어를 고르고 **저장**을 선택합니다. 적용될 때까지 소스 상세에 **적용 대기 중**이 표시됩니다. 변경은 리포지토리의 GitHub Actions 워크플로가 다음에 동기화할 때 적용되며, **동기화** 버튼으로는 적용되지 않습니다.
2. 워크플로의 `base-locale:` 값을 같은 언어로 고칩니다.
3. 워크플로를 실행합니다. 미전송 변경 사항이 있으면 리포지토리 업데이트가 보류됩니다. 변경 사항을 게시하거나 정리한 뒤 워크플로를 다시 실행합니다.

[리포지토리에서 동기화](../sync/revert.md#resync)는 값을 교체하지만 현재 기준 언어는 그대로 둡니다.

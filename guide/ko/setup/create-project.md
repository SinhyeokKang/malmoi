# 프로젝트 만들기

리포지토리를 연결하고 Malmoi가 관리할 번역 파일을 골라 프로젝트를 만듭니다.

시작하기 전에: 인증된 이메일로 로그인하고 **프로젝트**로 가서 **새 프로젝트**를 선택합니다. 활성 프로젝트는 세 개까지 소유할 수 있습니다. 첫 단계에서 리포지토리를 연결합니다. [GitHub 연결](connect-github.md)이나 [GitLab 연결](connect-gitlab.md)을 따른 뒤 아래로 이어 가세요.

## 파일 고르기 {#choose-files}

1. 감지된 파일을 고릅니다. 언어가 하나뿐인 파일도 지원합니다.
2. 파일이 감지되지 않으면 **경로 직접 지정**을 선택하고 지원하는 경로와 형식을 입력합니다. 경로 예시는 [지원 파일 형식](../reference/formats.md#formats)을 참고하세요.
3. 미리보기를 확인한 뒤 **다음**을 선택합니다.

Malmoi는 고른 파일 묶음마다 소스 하나를 보여 줍니다. 소스마다 기준 언어가 달라도 됩니다.

![감지된 번역 파일 묶음 두 개를 고르고 그중 하나의 키와 값을 미리 보는 4단계 중 2단계](/guide/create-files.webp "감지된 파일을 고르고 키를 확인합니다.")

## 프로젝트 정보 입력 {#confirm-project}

1. 소스마다 **기준 언어**를 확인합니다. 기준 언어의 파일을 기준으로 키 목록을 만들며, 다른 언어에만 있는 키는 포함되지 않습니다.
2. 프로젝트 **이름**과 **주소**를 입력합니다. 주소는 프로젝트 URL에 들어가는 이름으로, Malmoi 전체에서 고유해야 하고 나중에 바꿀 수 없습니다.
3. [한도](../reference/limits.md#files)에서 파일과 크기 한도를 확인한 뒤 **프로젝트 만들기**를 선택합니다.

![프로젝트 이름과 주소를 채우고 소스의 기준 언어로 영어를 고른 4단계 중 3단계](/guide/create-name.webp "프로젝트를 만들기 전에 기준 언어, 이름, 주소를 확인합니다.")

프로젝트는 바로 준비됩니다. 마지막 단계에 **Malmoi 준비 완료**가 표시되며, 곧바로 번역하고 팀원을 초대할 수 있습니다.

## 설정 마무리 {#finish-setup}

![푸시 토큰과 복사 버튼, 리포지토리에 저장할 워크플로 파일이 보이는 4단계 중 4단계 Malmoi 준비 완료 화면](/guide/create-ready.webp "이 페이지를 떠나기 전에 푸시 토큰과 워크플로를 복사합니다.")

1. 준비 완료 페이지에 표시된 푸시 토큰을 복사합니다. 토큰은 한 번만 표시되며, 잃어버리면 나중에 **설정**에서 교체합니다.
2. [워크플로 추가](workflow.md)를 따라 워크플로와 시크릿을 추가합니다.
3. **프로젝트 열기**를 선택해 프로젝트 홈으로 갑니다.

프로젝트를 만든 사람은 **소유자**가 됩니다.

GitLab 프로젝트라면 마지막 단계에 워크플로 대신 CI 작업이 표시됩니다. [GitLab CI 작업 추가](gitlab-ci.md)를 참고하세요.

## 다음 단계 {#next}

워크플로가 없어도 야간 실행이 하루 한 번 프로젝트를 최신 상태로 유지합니다. 워크플로를 추가하면 커밋마다 프로젝트가 업데이트되고, 첫 실행 뒤부터 코드 사용처가 표시됩니다. 워크플로가 실패해도 프로젝트가 준비되지 않은 상태로 돌아가지는 않습니다.

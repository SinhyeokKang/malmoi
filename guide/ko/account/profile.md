# 계정

계정에서 프로필, 로그인 수단, GitHub·GitLab 연결, 활성 세션을 관리합니다.

시작하기 전에: 오른쪽 위의 계정 메뉴를 열고 **계정**을 선택합니다.

## 프로필 수정 {#profile}

1. 이름을 고치고 **저장**을 선택합니다. 저장이 끝나면 **저장됨**이 표시됩니다.
2. 사진을 바꾸려면 **업로드**를 선택하고 3MB 이하의 PNG 또는 JPEG를 고릅니다. 업로드가 끝나면 프로필 사진이 바뀝니다.

사진은 자동으로 크기가 조정되며, 올린 원본 파일은 보관하지 않습니다. GitLab에서는 사진을 받지 않습니다. GitLab으로 처음 가입하면 이름의 첫 글자가 표시됩니다. 사진은 여기서 올릴 수 있습니다.

![프로필, GitHub·GitLab·Google 로그인 수단, GitHub App 영역이 있는 계정 페이지](/guide/account.webp "계정에서 프로필과 로그인 수단을 수정합니다.")

## 로그인 수단 관리 {#sign-in-methods}

mal-moi.com에는 GitHub, GitLab, Google 순서로 로그인 수단이 표시됩니다. 셀프 호스팅 설치본에는 사용하도록 설정한 수단만 표시됩니다. 다른 로그인 수단의 **연결**을 선택하고 같은 이메일 주소로 로그인합니다. 마지막 남은 수단은 제거할 수 없으며, 계정 화면에 **유일한 로그인 수단입니다.** 문구가 표시됩니다.

GitLab에서 Malmoi를 이미 승인했다면 GitLab 화면 없이 바로 돌아올 수 있습니다.

## 리포지토리 연결 {#connections}

리포지토리 접근 권한을 관리하려면 [GitHub 연결 관리](../github/connection.md) 또는 [GitLab 토큰과 연결 관리](../gitlab/connection.md)를 참고하세요. 로그인 수단과 리포지토리 연결은 별개입니다. **GitLab PAT**에서 아직 연결하지 않은 토큰 행은 **GitLab 토큰**으로 표시됩니다.

GitLab으로 로그인해도 토큰이 자동으로 연결되지는 않으며, GitLab 로그인 수단을 해제해도 연결된 토큰은 남습니다. 토큰을 삭제하려면 GitLab PAT 영역에서 **연결 해제**를 선택하고 확인창에서 **토큰 연결 해제**를 선택합니다. 이 토큰을 쓰던 프로젝트는 소유자가 다시 연결할 때까지 동기화와 게시가 멈춥니다. 토큰을 삭제해도 GitLab 로그인 수단은 남습니다.

## 세션에서 로그아웃 {#sessions}

1. **모든 기기에서 로그아웃**을 선택합니다.
2. 대화상자의 확인 버튼을 누릅니다. GitHub에서 계속, GitLab에서 계속, Google에서 계속 중 하나가 표시됩니다. Malmoi가 연결된 로그인 수단 중 하나를 고르며, 그 서비스의 본인 확인을 거칩니다.

GitLab에서 Malmoi를 이미 승인했다면 GitLab 화면 없이 바로 돌아올 수 있습니다.

지금 사용 중인 기기에서도 로그아웃됩니다.

개인 토큰과 연결된 앱도 함께 끊깁니다. AI 에이전트는 [새 토큰을 만들거나](../ai-agents/token.md) [다시 연결할](../ai-agents/browser.md) 때까지 Malmoi에 접근할 수 없습니다.

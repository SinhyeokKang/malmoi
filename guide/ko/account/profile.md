# 계정

계정에서 프로필, 로그인 수단, GitHub·GitLab 연결, 활성 세션을 관리합니다.

시작하기 전에: 오른쪽 위의 계정 메뉴를 열고 **계정**을 선택합니다.

## 프로필 수정 {#profile}

1. 이름을 고치고 **저장**을 선택합니다. **저장됨**이 변경을 확인해 줍니다.
2. 사진을 바꾸려면 **업로드**를 선택하고 3MB 이하의 PNG 또는 JPEG를 고릅니다. 업로드가 끝나면 프로필 사진이 바뀝니다.

사진은 자동으로 크기가 조정되며, 올린 원본 파일은 보관하지 않습니다.

![프로필, 로그인 수단, GitHub App, GitLab PAT 영역이 있는 계정 페이지](/guide/account.webp "계정에서 프로필과 로그인 수단을 수정합니다.")

## 로그인 수단 관리 {#sign-in-methods}

다른 로그인 수단의 **연결**을 선택하고 같은 이메일 주소로 로그인합니다. 마지막 남은 수단은 제거할 수 없으며, 계정 화면에 **유일한 로그인 수단입니다.** 문구가 표시됩니다.

## GitHub 연결 관리 {#github-connection}

프로젝트 소유자는 **GitHub App** 영역에서 리포지토리 선택을 승인하고 설치 권한을 관리합니다. 이것은 로그인과 별개입니다. 번역자는 이 영역을 건너뛰어도 됩니다.

승인이 만료되면 **GitHub App 다시 승인**을 선택합니다. 이미 연결된 프로젝트는 승인을 업데이트하는 동안에도 계속 동기화됩니다.

![계정 페이지를 GitHub App과 GitLab PAT 구역까지 내려, 각 구역에 연결된 계정과 버튼이 보이고 그 아래에 세션이 있는 모습](/guide/account-connections.webp "GitHub App과 GitLab PAT 구역에서 리포지토리 접근을 관리합니다.")

## GitLab 토큰 관리 {#gitlab-token}

GitLab.com 리포지토리를 쓰는 프로젝트 소유자는 **GitLab PAT** 영역에 GitLab 개인 액세스 토큰을 연결합니다. 번역자는 이 영역을 건너뛰어도 됩니다.

1. 연결된 토큰이 없다면 **GitLab에서 토큰 만들기**를 선택해 `api` 스코프가 있는 레거시 개인 액세스 토큰을 만들고, **개인 액세스 토큰**에 붙여 넣은 뒤 **연결**을 선택합니다.
2. 배지를 확인합니다. **연결됨**, 토큰이 14일 안에 만료되면 **만료 예정**, 만료되었으면 **만료됨**이 표시됩니다. 이 영역에는 만료일과 이 연결을 쓰는 프로젝트 수도 표시됩니다. 만료일까지 14일이 남지 않으면 영역 맨 위의 안내가 남은 일수를 알려 줍니다.
3. 토큰을 새로 바꾸려면 **토큰 교체**를 선택하고 같은 GitLab 계정의 새 토큰을 붙여 넣습니다. 이 연결을 쓰는 프로젝트는 바로 새 토큰으로 바뀝니다. 다른 GitLab 계정의 토큰은 받지 않으므로, 계정을 바꾸려면 먼저 연결을 해제합니다.

**연결 해제**를 선택하면 Malmoi에 저장된 토큰이 삭제됩니다. 그 토큰을 쓰던 프로젝트는 **연결 끊김**으로 표시되고, 프로젝트 소유자가 프로젝트 **설정**에서 다시 연결할 때까지 동기화와 게시가 멈춥니다. **로그**에는 연결이 해제되었다는 기록이 남습니다. Malmoi에서 연결을 해제해도 GitLab의 토큰은 철회되지 않으니, 더 쓰지 않는다면 GitLab에서 철회하세요.

내가 연결한 프로젝트는 내 토큰으로 게시하므로, GitLab에 남는 커밋과 MR(GitLab의 *merge request*)은 내 GitLab 계정의 이름으로 기록됩니다.

## 세션에서 로그아웃 {#sessions}

1. **모든 기기에서 로그아웃**을 선택합니다.
2. 대화상자의 확인 버튼을 누릅니다. GitHub로 계속 또는 Google로 계속 중 하나가 표시됩니다. Malmoi가 연결된 로그인 수단 중 하나를 고르며, 그 서비스의 본인 확인을 거칩니다.

지금 사용 중인 기기에서도 로그아웃됩니다.

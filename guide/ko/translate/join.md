# 프로젝트 참여

초대 메일을 열고 초대받은 이메일 주소로 로그인해 팀에 참여합니다.

초대는 그 초대를 받은 주소에 묶여 있습니다. GitHub나 Google로 로그인할 수 있습니다.

## 초대 수락 {#join}

1. 초대 메일의 링크를 엽니다.
2. 초대받은 주소로 로그인합니다. GitHub로 로그인한다면 초대받은 주소가 GitHub 기본 이메일이어야 합니다.
3. **초대 수락**을 선택합니다. Malmoi가 프로젝트를 엽니다.

![초대받은 이메일 주소, 편집자 역할의 프로젝트, 초대 수락 버튼이 보이는 초대 페이지](/guide/accept-invitation.webp "주소를 확인한 뒤 초대를 수락합니다.")

보관된 프로젝트의 초대는 수락할 수 없습니다. 초대를 수락했거나, 7일이 지났거나, 프로젝트 소유자가 철회하거나 다시 보내면 링크는 더 이상 동작하지 않습니다. 링크는 초대받은 주소에서만 동작하니 다른 사람에게 전달하지 마세요.

## 초대 문제 해결 {#invitation-problems}

다른 주소로 로그인했다면 **다른 계정으로 로그인**을 선택하고 초대받은 주소를 사용합니다. 링크가 만료되었거나 잘못된 주소로 보내졌다면 프로젝트 소유자에게 올바른 주소로 새 초대를 요청하세요.

# 내 계정

계정에서 프로필, 로그인 수단, GitHub 연결, 활성 세션을 관리합니다.

시작하기 전에: 오른쪽 위의 아바타 메뉴를 열고 **계정**을 선택합니다.

## 프로필 수정 {#profile}

1. 이름을 고치고 **저장**을 선택합니다. **저장됨**이 변경을 확인해 줍니다.
2. 사진을 바꾸려면 **업로드**를 선택하고 3MB 이하의 PNG 또는 JPEG를 고릅니다. 업로드가 성공하면 아바타가 바뀝니다.

사진은 자동으로 크기가 조정되며 원본 파일은 보관하지 않습니다.

![프로필, 로그인 수단, GitHub App 영역이 있는 계정 페이지](/guide/account.webp "계정에서 프로필과 로그인 수단을 수정합니다.")

## 로그인 수단 관리 {#sign-in-methods}

다른 공급자의 **연결**을 선택하고 같은 이메일 주소로 로그인합니다. 마지막 남은 수단은 제거할 수 없으며, 계정 화면에 **유일한 로그인 수단입니다.**라고 표시됩니다.

## GitHub 연결 관리 {#github-connection}

프로젝트 소유자는 **GitHub App** 영역에서 저장소 선택을 승인하고 설치 권한을 관리합니다. 이것은 로그인과 별개입니다. 번역자는 이 영역을 건너뛰어도 됩니다.

승인이 만료되면 **GitHub App 다시 승인**을 선택합니다. 이미 연결된 프로젝트는 승인을 갱신하는 동안에도 계속 동기화됩니다.

## 세션에서 로그아웃 {#sessions}

1. **모든 기기에서 로그아웃**을 선택합니다.
2. 대화상자의 확인 버튼을 누릅니다. GitHub로 계속, Google로 계속, 또는 **확인하고 모든 기기에서 로그아웃** 중 하나가 표시됩니다. 공급자는 Malmoi가 고르며, 그 공급자의 로그인 확인을 따릅니다.

지금 사용 중인 기기에서도 로그아웃됩니다.

# 자주 묻는 질문

Malmoi에 대해 자주 묻는 질문에 짧게 답하고, 자세히 설명하는 페이지로 안내합니다.

## Malmoi는 무엇을 하나요? {#what-is-malmoi}

Malmoi는 GitHub 리포지토리용 번역 관리(i18n) 도구입니다. 기존 번역 파일을 찾아 팀이 브라우저에서 편집하게 하고, 파일 구성을 바꾸지 않은 채 저장한 변경 사항을 PR로 돌려보냅니다. [동기화의 원리](sync/README.md#how-it-works)를 참고하세요.

## 번역자에게 Git이나 GitHub 계정이 필요한가요? {#translators}

아니요. 번역자는 GitHub나 Google로 로그인해 브라우저에서 편집하고 **게시**를 선택합니다. Git은 쓰지 않습니다. [프로젝트 참여](translate/join.md#join)를 참고하세요.

## 역할은 어떤 것이 있나요? {#roles}

**소유자**와 **편집자** 둘입니다. 편집자는 번역을 편집하고 게시합니다. 소유자는 여기에 더해 리포지토리 연결, 소스, 멤버, 동기화를 관리합니다. [번역자 초대](setup/members.md#roles)를 참고하세요.

## 어떤 파일 형식을 지원하나요? {#formats}

JSON·YAML 카탈로그, Chrome 확장 메시지, TypeScript·JavaScript 코드 사전을 지원합니다. 코드 사전은 언어마다 파일 하나여도 되고, 모든 언어가 한 파일에 있어도 됩니다. [지원 파일 형식](reference/formats.md#formats)을 참고하세요.

## Malmoi가 파일을 새로 써 버리나요? {#file-structure}

값은 Malmoi가 채우고, 파일의 모양은 기존 파일을 따릅니다. YAML 카탈로그와 코드 사전은 주석, 빈 줄, 키 순서를 지키고, JSON 파일은 들여쓰기와 이스케이프를 지킵니다. [파일 구조 보존](reference/formats.md#file-structure)을 참고하세요.

## 번역은 어떻게 리포지토리로 돌아가나요? {#pull-request}

**게시**하면 저장한 변경 사항이 PR 하나에 담기고, 개발팀이 검토해 머지합니다. 그 PR이 열려 있는 동안 다음 게시는 새 PR을 열지 않고 같은 PR을 업데이트합니다. [변경 사항 게시](translate/publish.md#publish)를 참고하세요.

## 번역하는 동안 코드가 바뀌면 어떻게 되나요? {#code-changes}

Malmoi는 두 쪽을 병합하지 않습니다. 미전송 변경 사항이 있거나 Malmoi PR이 열려 있으면 리포지토리 업데이트 전체가 보류되고, 로그에 **보류**로 표시됩니다. 변경 사항을 게시하고 PR을 머지하거나 닫으면 다음 업데이트가 반영됩니다. [코드가 바뀌면](sync/push.md#deferred)을 참고하세요.

## 코드에서 키를 지우면 번역은 어떻게 되나요? {#removed-keys}

지우지 않고 보존합니다. 나중 커밋에서 키가 돌아오면 번역도 함께 돌아옵니다. [제거된 키 보존](sync/push.md#removed-keys)을 참고하세요.

## 워크플로를 꼭 추가해야 하나요? {#workflow}

아니요. 워크플로가 없으면 야간 실행이 하루 한 번 리포지토리 변경을 가져옵니다. 워크플로를 추가하면 커밋할 때마다 변경이 들어옵니다. [야간 동기화 또는 워크플로](sync/nightly.md#workflow)를 참고하세요.

## Malmoi에 유료 플랜이 있나요? {#pricing}

아니요. Malmoi에는 유료 플랜이 없으며 MIT 라이선스로 공개된 오픈 소스입니다.

## Malmoi가 번역을 대신 해 주나요? {#machine-translation}

아니요. Malmoi에는 기계 번역도 번역 메모리도 없습니다. 직접 쓰는 AI 에이전트를 연결할 수 있고, 에이전트가 쓴 값은 브라우저와 같은 검사를 거쳐 내 편집으로 저장됩니다. [AI 에이전트 연결](ai-agents/README.md)을 참고하세요.

## 승인 단계가 있나요? {#review}

아니요. **검토 필요**는 원문이 바뀐 번역에 붙는 표시일 뿐이고, 저장하면 사라집니다. [번역 편집](translate/edit.md#save)을 참고하세요.

## Malmoi가 지원하지 않는 기능은 무엇인가요? {#not-supported}

ICU 복수형, 동시 편집, 세밀한 권한, 인컨텍스트 편집, 스크린샷 첨부, 번역자 노트, 승인 워크플로, 번역 메모리, 내장 기계 번역·AI 번역은 지원하지 않습니다.

## 프로젝트와 멤버는 몇 개까지 되나요? {#limits}

활성 프로젝트는 3개까지 소유할 수 있고, 프로젝트의 멤버가 10명이 되면 새 초대를 보낼 수 없습니다. 프로젝트를 보관하면 자리가 하나 빕니다. [한도](reference/limits.md#limits)를 참고하세요.

## 화면 언어, 시간대, 테마를 바꿀 수 있나요? {#preferences}

네, **환경설정**에서 바꿉니다. 내 화면에만 적용되고, 프로젝트가 번역하는 언어는 바뀌지 않습니다. [환경설정](account/preferences.md#preferences)을 참고하세요.

## Malmoi는 나에 대해 무엇을 저장하나요? {#privacy}

GitHub나 Google에서 받은 이름, 이메일 주소, 프로필 사진과 프로젝트 멤버십, 그리고 각 번역을 마지막으로 바꾼 사람을 저장합니다. 이름, 이메일 주소, 연결 토큰은 암호화해 저장하며, Malmoi는 데이터를 팔거나 광고에 쓰지 않습니다. 전체 목록은 사용하는 사이트의 **개인정보 처리방침**에 있으며, 페이지 하단에 링크가 있습니다.

## 계정은 어떻게 삭제하나요? {#delete-account}

삭제 버튼은 없습니다. 페이지 하단에 링크된, 사용하는 사이트의 **개인정보 처리방침**에 적힌 주소로 요청합니다. mal-moi.com에서는 30일 안에 답하며, 다른 사이트는 운영자의 방침이 기한을 정합니다. 번역은 프로젝트에 남지만, 더 이상 나와 연결되지 않습니다.

# 되돌리기와 다시 동기화

프로젝트 소유자는 변경한 값을 마지막으로 전송된 값으로 되돌리거나, 프로젝트의 값을 리포지토리의 파일로 교체할 수 있습니다.

시작하기 전에: 소유자 전용 기능을 쓰기 전에 편집 중인 번역을 저장하거나 취소합니다.

## 값 되돌리기 {#revert}

1. **번역**에서 미전송 변경 사항이 있는 키를 고르고 **마지막으로 보낸 값으로 되돌리기**를 선택합니다.
2. 확인 대화상자에 나열된 해당 언어를 읽습니다. 다른 팀원이 저장한 것까지 포함해 이 키의 모든 미전송 변경 사항이 대상입니다.
3. 마지막으로 전송이 확인된 값으로 되돌리려면 **번역 되돌리기**를, 변경 사항을 남기려면 **취소**를 선택합니다.

![마지막으로 전송이 확인된 값으로 돌아가는 언어 하나를 알려 주고 취소와 번역 되돌리기 버튼이 있는 되돌리기 확인 화면](/guide/revert-confirm.webp "나열된 언어를 확인한 뒤 번역 되돌리기를 선택합니다.")

동기화가 진행 중이면 Malmoi가 **동기화 중…** 안내와 함께 늦어도 언제 다시 되돌릴 수 있는지를 보여 주며, 아무것도 되돌리지 않습니다. 해당 언어 중 하나라도 이전에 보낸 값이 없으면 아무것도 되돌리지 않습니다. 대화상자가 열려 있는 동안 누군가 값을 바꾸면 확인하기 전에 **다시 검토**를 선택합니다. 되돌려도 **검토 필요**는 바뀌지 않습니다.

## 리포지토리에서 동기화 {#resync}

1. **홈** 또는 **번역** 맨 위에서 **동기화**를 선택합니다.
2. 미전송 변경 사항이 있으면 대화상자에 버려질 변경 사항 수가 표시됩니다.
3. 미전송 변경 사항이 있으면 **변경 사항을 버리고 동기화**를, 없으면 **리포지토리에서 동기화**를 선택합니다. 변경 사항을 남기려면 대화상자를 닫습니다.
4. 대화상자에서 기다립니다. 동기화가 진행되는 동안 대화상자는 열려 있고, 결과를 같은 자리에 보여 주며 제목이 결과를 알려 줍니다. 다 읽었으면 **닫기**를 선택합니다.

![미전송 변경 사항 1건이 버려진다고 경고하고 변경 사항을 버리고 동기화 버튼이 있는 동기화 확인 화면](/guide/sync-discard.webp "동기화하기 전에 버려질 변경 사항 수를 확인합니다.")

동기화는 프로젝트 소유자만 쓸 수 있으며, 편집자에게는 번역 화면에서 꺼진 상태로 보입니다. 페이지를 열 때 이미 다른 동기화가 진행 중이었다면 **동기화**가 그 이유와 함께 꺼집니다. 동기화가 진행되는 동안에는 이 프로젝트에서 아무도 번역을 저장하거나 되돌릴 수 없습니다. 다른 멤버에게는 **동기화 중…** 안내와 함께 늦어도 언제 다시 저장할 수 있는지가 보이고, 입력한 텍스트는 남습니다. 1분쯤 지나도 결과가 나오지 않으면 대화상자가 결과는 [로그](logs.md)에 남는다고 알리고 닫을 수 있게 합니다. 동기화는 기준 브랜치의 파일을 직접 읽습니다. 결과에는 읽지 못했거나 교체되지 않은 소스가 나열됩니다. 읽기에 성공한 파일의 값으로 교체합니다. 확인한 뒤에 저장된 변경 사항과 교체하지 못한 변경 사항은 그대로 남으니, 결과에서 남은 변경 사항 수를 확인하세요.

## 다음 단계 {#next}

계속하기 전에 결과에서 실패했거나 교체되지 않은 소스를 확인합니다. 수동 동기화를 마치려고 워크플로를 실행할 필요는 없습니다.

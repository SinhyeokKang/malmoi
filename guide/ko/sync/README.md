# 동기화의 원리

리포지토리의 변경 사항은 Malmoi로 동기화되고, 저장한 번역은 게시를 통해 개발팀의 검토를 받습니다.

## 동작 방식 {#how-it-works}

어떤 키(앱 텍스트 한 조각)가 있는지는 리포지토리가 정합니다. 리포지토리 업데이트 사이에는 Malmoi가 번역 값을 관리하고, 리포지토리 업데이트가 들어오면 Malmoi의 값이 리포지토리의 값으로 교체됩니다. 두 값을 합치거나 어느 쪽을 남길지 고르지 않는 병합 없는 흐름입니다. 미전송 변경 사항이 있거나 Malmoi의 PR이 아직 열려 있으면 자동 업데이트는 보류됩니다. 리포지토리 업데이트는 커밋마다 리포지토리의 워크플로가 보내거나, 하루 한 번 [야간 실행](nightly.md#repository-changes)이 가져옵니다.

**게시**는 Malmoi의 값을 PR(GitHub의 *pull request*)에 담아 개발팀이 검토하고 머지할 수 있게 합니다.

리포지토리에서 들어오는 흐름은 [코드가 바뀌면](push.md)을, 리포지토리로 돌아가는 흐름은 [PR 머지](merging.md)를 참고하세요.

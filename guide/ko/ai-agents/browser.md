# 브라우저로 로그인

Claude Code, Codex, claude.ai는 브라우저에서 Malmoi에 로그인하는 방식으로 연결할 수 있어 토큰을 복사할 필요가 없습니다.

## 에이전트 연결하기 {#browser}

1. 에이전트에 서버 주소를 추가합니다. 주소를 복사하려면 **MCP 커넥터** 페이지의 **연결된 앱** 카드에서 **서버 URL 복사**를 선택하고, 아래 설정 예시의 `SERVER_URL` 자리에 넣습니다. 설정 예시에는 토큰이 들어 있지 않습니다.
2. 에이전트에서 로그인을 시작합니다(각 설정 예시 아래 설명 참고). 브라우저에 **Malmoi에 앱 연결**이 열립니다.
3. Malmoi에 로그인되어 있지 않다면 **GitHub로 계속하기**, **GitLab으로 계속하기**, **Google로 계속하기** 중 하나를 선택합니다. 같은 화면으로 돌아옵니다. 표시된 계정이 내 것이 아니면 **다른 계정인가요?** 링크를 선택해 바꿉니다.
4. 앱 이름과 그 아래의 주소를 확인합니다. 이름은 앱이 스스로 정한 것이므로, 어느 앱이 요청하는지는 주소로 알 수 있습니다.
5. **유효 기간**, **권한**, **범위**를 고릅니다. [개인 토큰](token.md#token)과 같은 선택지입니다.
6. **승인**을 선택합니다. 연결이 완료되면 브라우저에서 에이전트로 돌아갑니다. **거부**를 선택하면 연결하지 않고 에이전트로 돌아갑니다.

![Claude를 위한 Malmoi에 앱 연결 화면: 다른 계정인가요? 링크가 붙은 로그인 계정, 앱 이름과 주소, 유효 기간을 90일로 정하고 번역·게시가 체크된 권한](/guide/oauth-consent.webp "앱의 주소를 확인한 뒤 앱이 할 수 있는 일을 고릅니다.")

같은 앱을 전에 연결한 적이 있으면 화면에 기존 연결이 있다고 표시됩니다. 다시 승인하면 기존 연결이 교체되고, 다른 컴퓨터에서 그 앱이 로그아웃될 수 있습니다. 로그인 요청은 10분 동안 유효합니다. 만료되었거나 이미 응답한 요청이라면 에이전트에서 다시 시작하세요.

### Claude Code {#browser-claude-code}

프로젝트 루트의 `.mcp.json`에 다음을 추가합니다.

```json title=".mcp.json"
{
  "mcpServers": {
    "malmoi": {
      "type": "http",
      "url": "SERVER_URL"
    }
  }
}
```

그런 다음 Claude Code에서 `/mcp`를 실행하고 방금 추가한 서버를 골라 Authenticate를 선택합니다. 브라우저가 열리면 Malmoi에 로그인합니다.

설정에 개인 토큰이 든 `headers` 줄이 이미 있다면 먼저 지우세요. 그 줄이 있는 동안 Claude Code는 계속 토큰을 씁니다.

### Codex {#browser-codex}

Codex 설정 파일에 다음을 추가합니다.

```toml title="~/.codex/config.toml"
[mcp_servers.malmoi]
url = "SERVER_URL"
```

그런 다음 `codex mcp login` 뒤에 설정 예시에 있는 서버 이름을 붙여 실행합니다. 브라우저가 열리면 Malmoi에 로그인합니다.

설정에 `bearer_token_env_var` 줄이 이미 있다면 먼저 지우세요. 그 줄이 있는 동안 Codex는 계속 토큰을 씁니다.

### claude.ai {#browser-claude-ai}

claude.ai는 자체 설정에서 연결하므로 편집할 파일이 없습니다.

1. claude.ai에서 **Customize** → **Connectors**를 열고 **Add**, 이어서 **Add custom connector**를 선택합니다.
2. 복사한 서버 주소를 붙여 넣고 Malmoi 같은 이름을 붙입니다.
3. **Connect**를 선택합니다. 창이 열리면 위 단계처럼 Malmoi에 로그인하고 승인합니다.

Team 또는 Enterprise 요금제에서는 claude.ai 조직의 소유자만 사용자 지정 커넥터를 추가할 수 있습니다. 소유자에게 먼저 Malmoi를 추가해 달라고 요청한 뒤 직접 **Connect**를 선택하세요. Free 요금제에서는 사용자 지정 커넥터를 하나만 쓸 수 있습니다.

## 연결된 앱 {#connected-apps}

승인한 에이전트는 **MCP 커넥터** 페이지의 **연결된 앱**에 앱별로 하나씩 표시됩니다. 권한, 범위, 마지막 사용 시각, 만료 시각도 함께 확인할 수 있습니다.

1. 사이드바에서 **MCP 커넥터**를 엽니다.
2. 앱을 찾습니다. 두 연결의 이름이 같을 수 있으며, 이름 아래의 주소로 구별합니다.
3. **연결 해제**를 선택한 뒤 **앱 연결 해제**를 선택합니다.

![연결된 앱 두 개(Claude Code와 주소로 표시된 Codex 앱)가 각각 권한, 범위, 마지막 사용, 만료, 연결 해제 버튼과 함께 개인 토큰 카드 위에 보이는 MCP 커넥터 페이지](/guide/mcp-connector.webp "더 이상 쓰지 않는 앱의 연결을 해제합니다.")

앱은 다음 요청부터 접근 권한을 잃습니다. 다른 앱과 개인 토큰은 계속 동작합니다. claude.ai에서 커넥터를 제거해도 Malmoi의 연결은 남습니다. 이 페이지에서도 **연결 해제**를 선택하세요. 만료된 연결은 **만료됨**으로 목록에 남습니다. 계속 쓰려면 에이전트에서 앱을 다시 승인하세요.

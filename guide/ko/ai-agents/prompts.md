# 프롬프트 예시

자주 쓰는 요청 몇 가지에 에이전트가 무엇을 하는지, 그리고 각 요청 뒤에 무엇을 확인할지 알아봅니다.

## 해 볼 만한 프롬프트 {#prompts}

### 이 리포지토리를 Malmoi에 연결해 줘 {#connect-repo}

에이전트는 리포지토리를 나열하고, 번역 파일을 감지하고, 첫 동기화와 함께 프로젝트를 만듭니다. 브라우저의 [프로젝트 만들기](../setup/create-project.md)와 같습니다. 결과에는 워크플로 파일과 푸시 토큰이 들어 있습니다. 푸시 토큰을 저장한 뒤, 고른 기준 브랜치에 워크플로 파일을 커밋하도록 에이전트에게 요청하세요.

GitHub 연결이나 Malmoi GitHub App이 없으면 에이전트가 **계정** 링크를 돌려줍니다. 브라우저에서 그곳을 마무리한 뒤 에이전트에게 다시 시도하도록 요청하세요. 번역 파일을 찾지 못하면 링크가 브라우저에서 프로젝트 설정을 열어 주며, 거기서 형식을 직접 고를 수 있습니다.

### 푸시 토큰을 저장해 줘 {#push-token}

푸시 토큰은 에이전트 대화에 한 번 표시되며, 그 대화는 AI 서비스 제공자에게도 전송됩니다. 그것이 신경 쓰인다면 나중에 브라우저의 **설정**에서 토큰을 교체하세요. 토큰을 표준 입력으로 넘겨 리포지토리의 `PUSH_TOKEN` 시크릿으로 저장하도록 에이전트에게 요청합니다.

```text
gh secret set PUSH_TOKEN --repo OWNER/REPO
```

`OWNER/REPO`를 리포지토리로 바꿉니다. `--body`는 붙이지 마세요. `--body -`는 대시 하나를 저장합니다. 워크플로가 그 시크릿을 읽으므로 이름은 `PUSH_TOKEN`이어야 합니다. 나머지 설정은 [워크플로 추가](../setup/workflow.md#push-token)를 참고하세요.

### 비어 있는 fr 번역을 채우고 게시해 줘 {#fill-and-publish}

에이전트는 프랑스어 값이 없는 키를 찾아 값을 쓰고 저장합니다. 그다음 변경 사항을 미리 보고 PR 하나로 게시합니다. 브라우저의 **게시**와 같습니다. 로그에는 저장과 게시가 내 이름으로 표시됩니다.

머지하기 전에 PR을 검토하세요. 에이전트는 토큰이 **번역·게시**를 허용할 때만 게시할 수 있습니다.

## 다음 단계 {#next}

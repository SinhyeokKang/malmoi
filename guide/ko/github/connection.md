# GitHub 연결 관리

계정에서 리포지토리 접근 권한을 관리하고 GitHub 승인을 업데이트합니다.

시작하기 전에: 오른쪽 위의 계정 메뉴를 열고 **계정**을 선택하세요.

## GitHub 연결 관리 {#github-connection}

프로젝트 소유자는 **GitHub App** 영역에서 리포지토리 선택을 승인하고 설치 권한을 관리합니다. 이 승인은 로그인과 별개입니다. 번역자는 이 영역을 건너뛰어도 됩니다.

승인이 만료되면 **GitHub App 다시 승인**을 선택합니다. 이미 연결된 프로젝트는 승인을 업데이트하는 동안에도 계속 동기화됩니다.

# Your account

Manage your profile, sign-in methods, GitHub connection, and active sessions in Account.

**Account** is available without a project. It is the place to edit the name teammates see, manage sign-in methods, connect the GitHub App account, and revoke active sessions.

## Update your profile {#profile}

Change the name shown to teammates and upload a profile picture. The stored picture is normalized before it is saved; the original file and its metadata are not kept.

## Manage sign-in methods {#sign-in-methods}

Account lists the GitHub and Google methods attached to the account. Connecting another method uses a challenge round trip; removing a method follows the account rules shown beside that method.

## Manage the GitHub connection {#github-connection}

The GitHub App connection lets you choose installations and repositories. It is separate from the OAuth method used to sign in, and it is read-only from the connection flow.

## Sign out of sessions {#sessions}

Use the session controls to revoke active sessions. A challenge confirms the action so an old session cannot authorize its own revocation.

# Malmoi

Set up a project to connect your repository, or join your team to edit and publish translations.

Choose Set up a project if you maintain the repository. Choose Translate if a project owner invited you to edit translations. The chapters below explain how source files, saved translations, and repository updates move through Malmoi.

## How Malmoi works {#how-it-works}

Your code decides which keys exist. Malmoi stores the translated values and never merges a repository value with an edited value. A repository update can wait while unpublished edits remain, and a Publish action sends saved edits back as one pull request.

Start with [Set up a project](setup/README.md) or [Translate](translate/README.md).

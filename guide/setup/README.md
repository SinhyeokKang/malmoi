# Set up a project

Connect a GitHub repository, choose your translation files, and invite your team.

Follow the setup pages in order: create the project, add Sources, add the workflow, then invite translators. Project owners can archive the project later without deleting its translations or activity history.

## Setup order {#setup-order}

Begin with [Create a project](create-project.md), then [Add sources](sources.md) and [Add the workflow](workflow.md). Finish with [Invite translators](members.md) when the first sync is ready.
